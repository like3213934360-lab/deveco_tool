# 差异分析规则

> 本文件定义 Skill 执行流程的 Step 5 和 Step 7 详细规则——差异类型识别、阈值设定和优先级规则。

## 差异类型识别规则

差异分析分为两层：Step 5 的初步差异识别和 Step 7 的最终差异分析（在行为等价审计之后执行）。两者的差异类型识别规则相同，此处合并定义。

### 优先级排序

差异类型按优先级从高到低排列。**ALREADY_IMPLEMENTED 优先级最高**——在说"需要实现什么"之前，必须先确认"什么已经实现了"。

```yaml
差异类型识别规则:
  1. 现有代码已实现(优先级最高):
    规则: 需求中要求的功能在代码仓中已经有完整实现
    示例: 需求要求"滤镜选择器"但已有filterList包含5个滤镜选项
    处理: 标记为ALREADY_IMPLEMENTED，不需要新增代码
    优先级: 此规则优先级高于所有其他规则

  2. 未实现界面:
    规则: 需求中存在但代码仓中找不到对应组件
    示例: 需求定义了Tab组件但代码仓只有普通列表
    处理: 标记为需要新增实现

  3. 组件类型不匹配:
    规则: 需求中的组件类型与代码仓实现不一致
    示例: 需求是Card组件但代码仓是普通Div
    处理: 标记为需要替换组件类型

  4. 高级视觉效果缺失:
    规则: 需求包含特殊视觉效果但代码仓未实现
    示例: 需求定义了毛玻璃效果但代码仓是普通背景色
    处理: 标记为需要添加视觉效果
    检测项:
      - backdropBlur属性
      - backgroundBlurStyle属性（BlurStyle.COMPONENT_THICK等）
      - shadow属性
      - gradient属性

  5. 布局策略不匹配:
    规则: 需求推断的布局策略与代码仓实现不一致
    示例: 需求要求水平居中但代码仓是左对齐
    处理: 标记为需要调整布局

  6. 样式参数偏差:
    规则: 需求中的样式参数与代码仓实现偏差超过阈值
    示例: 需求定义圆角8dp但代码仓是4dp
    处理: 标记为需要调整样式
    阈值:
      - 尺寸偏差: >2px
      - 颜色偏差: >5%
      - 间距偏差: >2px

  7. 路由与通信缺失:
    规则: 需求提到的路由跳转或跨模块通信在代码仓中不存在
    处理: 标记为需要新增路由或通信机制

  8. 数据模型缺失:
    规则: 需求提到的数据实体在代码仓中不存在
    处理: 标记为需要新增数据模型
```

## 数据流完整性验证

在差异分析过程中，需要验证数据流的完整性。此验证与行为等价审计互补——行为审计关注"语义等价"，数据流验证关注"链路完整"。

### 数据流验证规则

```yaml
数据流完整性验证:
  RULE_01_数据源验证:
    规则: 确认数据是否从正确的源头获取
    检查: 数据源接口是否被正确实现，数据获取方法是否被正确调用

  RULE_02_传递链路验证:
    规则: 确认数据从源头到展示的完整传递路径
    检查: DataSource → ViewModel → Controller → Component → UI 的每一环是否完整

  RULE_03_回调参数完整性:
    规则: emitCallback/onCallback 的参数数量和类型必须两端匹配
    检查:
      - emit端的参数数量 === onCallback端的参数数量
      - emit端每个参数的类型 === onCallback端对应位置参数的类型
      - 两端参数的语义必须一致（不可漂移）

  RULE_04_状态传播验证:
    规则: @State/@Prop/@Link/@Provide/@Consume 的状态变更必须传播到所有依赖方
    检查: 状态变更是否触发了所有必要的UI刷新或逻辑更新

  RULE_05_默认值陷阱检测:
    规则: 新增参数必须有合理的默认值，避免现有调用方因缺少参数而行为异常
    检查: 新增参数是否提供了默认值，默认值是否与"不传参数"的语义一致
```

## 差异处理动作

对于每种差异类型，对应的标准处理动作：

| 差异类型 | 处理动作 | 输出位置 |
|---------|---------|---------|
| ALREADY_IMPLEMENTED | 标记已实现，不生成新代码 | 配套MD第五章"已实现功能点" |
| 未实现界面 | 新增页面/组件实现 | 配套MD第六章"新增界面" |
| 组件类型不匹配 | 替换组件类型 | 配套MD第六章"新增组件" |
| 高级视觉效果缺失 | 添加视觉效果属性 | 配套MD第六章"视觉效果升级" |
| 布局策略不匹配 | 调整布局参数 | 配套MD第六章"布局调整" |
| 样式参数偏差 | 调整样式参数 | 配套MD第六章"样式调整" |
| 路由与通信缺失 | 新增路由/通信机制 | 配套MD第六章"新增路由" |
| 数据模型缺失 | 新增数据模型 | 配套MD第六章"新增数据模型" |
