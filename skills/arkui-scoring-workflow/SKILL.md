## 本包工具绑定

上游文中所有「MCP 工具」在本包对应：

| 用途 | 本包工具 |
| --- | --- |
| 构建 | `build_project` |
| 推送并启动到设备/模拟器 | `start_app` |
| 确认可用目标 | `hdc_log`（`action: "list_devices"`） |
| 页面操作（点击、输入、滑动） | `perform_ui_action` |
| 截图并落到本地文件 | `perform_ui_action`，`{ "actionType": "screenshot", "localPath": "<绝对路径>" }` |
| 读取组件结构与 bounds | `get_app_ui_tree` |
| 评分 | `ui-reconstruction-score` 的 `scripts/ui_score.py` |

截图能力不依赖本包禁用的 `verify_ui` 那条链：`perform_ui_action` 的 screenshot 动作是独立的，
不需要任何校验任务 id。

`get_app_ui_tree` 是上游没有用到的一条证据来源：它给出组件 bounds，所以「前景组件是否侵入真实
状态栏」可以数值判定，而不是只靠像素带观察。存在结构证据时优先采信它。

## 目标

使用上表的工具完成 ArkUI 应用构建、推送模拟器或预览环境、页面操作、截图保存，并使用 `ui-reconstruction-score` skill 对比参考图与实现图，输出评分和问题。

## 输入

- 参考图路径，通常是 Figma 预览图、设计稿截图或 `Preview.png`
- ArkUI 工程路径
- 目标页面、路由、预览页或启动入口
- 系统 UI 策略、顶部/底部忽略区域配置；未提供时移动端默认 `ignoreTopPx=44`、`ignoreBottomPx=36`
- 一台已连接的 HarmonyOS 目标（真机或模拟器），以及「本包工具绑定」表中的工具

缺少参考图、ArkUI 工程路径、目标页面信息或必要工具时，立即终止并提示缺失项。

## 执行约束

- 构建、推送、启动页面、操作页面和截图必须使用「本包工具绑定」表中的工具。
- 推送优先使用已经在运行的目标。
- 禁止自行编写脚本、shell 自动化、截图替代程序或其他绕过这些工具的尝试来完成构建、推送、启动、页面操作或截图。
- 工具不可用、能力缺失或返回无法继续的错误时，立即终止并报告具体阻塞。
- 实现截图必须来自工具操作后的真实 ArkUI 页面、模拟器、设备或项目认可的预览环境。
- 每轮评分必须加载并**完整执行** `ui-reconstruction-score`；仅在文本中提及、读取其文件或声称已加载均不算执行。评分前必须获得本地参考图和本地实现截图。
- 每轮在运行评分脚本之前，先记录 `{ "skill": "ui-reconstruction-score", "round": N, "status": "invoked" }`。只有该轮独立生成且成功解析 `score.json` 和 `metrics.json` 后，才能将该记录更新为 `status=completed`。
- `ui-reconstruction-score` 不存在、加载失败、评分脚本失败或任一必需 JSON 缺失/不可解析时，立即返回 `status=blocked`；不得用人工目测或自然语言评分降级替代。
- 单次评分采样期间不得修改页面实现代码。完成本轮评分并输出问题后，视觉校准模式允许按本轮最多三个问题修改代码，再重新构建、截图和评分；重新评分后才计为下一轮完成。不得为了提高评分而关闭全屏、移除沉浸式配置、伪造系统栏或掩盖安全区问题。

- 顶部状态栏图标/文字和底部系统手势/小横条区域不参与像素评分；但这些区域必须用于诊断应用前景组件是否侵入真实系统区。

## 工作流

按顺序执行。

1. 检查输入：
   - 确认参考图存在且可打开。
   - 确认 ArkUI 工程路径、目标页面、入口配置和资源路径。
   - 用 `hdc_log`（`action: "list_devices"`）确认恰好有一个可用目标。
2. 构建并推送：
   - `build_project` 构建目标 ArkUI 工程或目标模块。
   - `start_app` 把应用装到目标并启动，优先使用已经在运行的目标。
   - 记录工具名、目标工程、目标模块和主要结果。
3. 进入目标页面：
   - 启动应用或预览页。
   - 根据目标路由或页面说明，用 `perform_ui_action` 完成必要点击、输入、返回、切换 tab 或页面跳转。
   - 截图前等待首屏图片、字体、动画和异步内容稳定。
4. 截图并保存：
   - `perform_ui_action`，`{ "actionType": "screenshot", "localPath": "<绝对路径>" }`，把当前实现截图落到本地文件。
   - 使用清晰命名，例如 `screenshots/<page>-candidate.png`。
   - 同时用 `get_app_ui_tree` 取一份结构快照，供第 5 步的重叠诊断做数值判定。
   - 记录参考图路径和实现截图路径。
5. 建立系统区排除和重叠诊断配置：
   - 读取系统 UI 策略、设计文档或调用方参数，确定顶部状态栏忽略高度和底部系统手势/小横条忽略高度；未提供时移动端默认 `ignoreTopPx=44`、`ignoreBottomPx=36`。
   - 顶部状态栏图标/文字、运营商、电量、Wi-Fi、信号以及底部系统手势/小横条只作为环境系统 UI 处理，不参与像素评分。
   - 不得因为参考图存在 mock 状态栏或 mock 小横条就要求实现图绘制对应内容。
   - 忽略区域不等于跳过安全区检查：如果页面标题、返回按钮、搜索框、卡片、头像、列表首项等应用前景组件进入真实状态栏区域，必须作为 `top_system_area_overlap_risk` 或 safe-area 问题报告。
   - 评分流程不得修改 `EntryAbility.ets`、不得切换 `setWindowLayoutFullScreen`、不得通过关闭沉浸来消除重叠。
6. 检查页面是否可比：
   - 直接查看参考图和实现截图。
   - 如果两个页面明显完全不同，先确认是否进入了明确的目标路由或页面状态。
   - 路由或页面状态不明确时，用 `perform_ui_action` 操作页面进入明确目标路由后重新截图。
   - 如果仍未发现与参考图相似的页面，输出明确结论：当前运行页面与参考页面不匹配，评分不可作为还原质量依据。
7. 使用 `ui-reconstruction-score` 评分：
   - 读取并遵守 `ui-reconstruction-score` skill。
   - 对参考图和实现截图运行评分流程，并传入系统区忽略参数，例如 `--ignore-top-px 44 --ignore-bottom-px 36`；如果调用方提供了真实安全区高度，使用调用方数值。
   - 打开 `score.json` 和 `metrics.json`，将 `ignored_top_status_px`、`ignored_bottom_system_px`、`system_area_diagnostics`、`top_system_area_overlap_risk` 相关 hints 展示给用户。
   - 输出总评分、可比性、分项评分和最多两个最明显、可定位的 UI 问题。
8. 三轮一组询问是否继续视觉校准：
   - 首次执行必须连续完成 3 轮构建/启动/截图/评分；前三轮之间不得询问用户是否继续，不得中断等待确认。
   - 每轮评分结束后都必须记录并展示本轮评分、截图路径、系统区诊断、问题点、严重度、本轮建议和修复摘要；如果本轮包含修复动作，必须先完成修复、重建、重截图和重评分，再计入该轮完成。
   - 第 3 轮完成后，必须展示三轮汇总，然后询问用户选择 `继续视觉校准` 或 `结束视觉校准并进入下一阶段`。
   - 评分 workflow 可以建议结束，但不得自行结束循环；没有用户明确选择结束时，不得宣称视觉校准完成。
   - 如果用户选择继续，只追加执行 1 轮校准；该追加轮完成后展示本轮评分、截图路径、系统区诊断、问题点、严重度和修复摘要，并再次询问是否继续。后续每次继续都只追加 1 轮，不再执行 3 轮一组。
   - 每轮最多处理调用方允许的问题数量；若调用方未指定，最多处理 3 个视觉问题。

## 输出要求

输出包含：

- 构建、推送、启动、页面操作和截图结果
- 参考图路径
- 实现截图路径
- 系统区忽略配置：顶部状态栏忽略高度、底部系统手势/小横条忽略高度
- 系统区诊断：顶部是否存在应用前景组件侵入状态栏的风险、底部系统手势区是否仅作为环境差异排除
- 页面可比性判断
- 总评分和可比性
- 最多两个问题，包含区域、问题、可能代码位置、严重度
- 本组是否询问用户继续视觉校准，以及用户选择结果
- 页面完全不匹配时的明确结论和已尝试进入的目标路由或页面状态

顶部手机状态栏中的时间、信号、Wi-Fi、运营商、电量或系统指示差异，以及底部系统手势/小横条差异，仅用于判断对齐和安全区，不作为像素评分问题输出。应用前景组件与状态栏重叠必须作为布局问题输出。

## 停止条件

- 缺少参考图、ArkUI 工程路径或目标页面信息。
- 缺少「本包工具绑定」表中的工具，或它们不具备构建、推送、启动、页面操作或截图能力。
- 构建、推送、启动或截图失败且没有其他工具路径可继续。
- 无法获得本地实现截图。
- 已确认当前运行页面与参考页面完全不匹配。
