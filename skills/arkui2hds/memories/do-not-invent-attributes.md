Object literal may only specify known properties, and 'strokeWidth' does not exist in type 'HdsDividerStyle'.```### 示例2：barFloatingStyle 的多个属性为 `HdsTabs` 的 `barFloatingStyle` 属性配置了多个不存在的属性：```typescript// 错误 - floatingType, borderWidth, borderColor, borderRadius, backgroundColor 都不存在.barFloatingStyle({  floatingType: 1,  borderWidth: 1,  borderColor: 0x1A000000,  borderRadius: 16,  backgroundColor: 0xFFFFFF,  materialEffect: { ... }})```报错：```Argument of type '{ floatingType: number; ... }' is not assignable to parameter of type 'HdsTabsFloatingStyle'. Object literal may only specify known properties, and 'floatingType' does not exist in type 'HdsTabsFloatingStyle'.```## 正确做法1. **只配置文档中明确说明的属性**2. **配置前先确认属性真实存在**3. **如果不确定，宁可不要添加该属性**```typescript// 正确 - 只配置存在的属性.barOverlap(true).barFloatingStyle({ ... })```## 重要原则- 严格遵循 skill 文档中的属性说明- 不要基于经验推测属性名称- 遇到类型错误时，删除不确认的属性，而不是尝试"修复"它## 相关文件- `C:\Users\z00893387\.codeagent\skills\arkui2hdseferences\components.md` - HDS组件详细说明
