## 无法自动核实的外部结果

恢复并不意味着所有副作用都能重做。设备缺少完成回执、原生 SDK 没有留下完成记录、云端 Profile 请求响应丢失且服务没有查询接口时，返回 `needs_input`，保留操作记录和必要资源保护。`resume_input` 只允许 `action=recheck`，核对已声明的输入和真实外部状态。不会让宿主随意编辑图状态，也不会伪造成功或盲目重发签名、安装、点击。

云端证书和设备有清单可核对；Profile 无查询接口的场景仍需外部核实。这个协议边界须在统一测试中覆盖“安全暂停”，不能声称有自动恢复成功的证据。
